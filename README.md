# INOX Smart UI Demo

A front-end-only React demo framework for exploring INOX Smart SaaS UI v1.0 and future UI versions.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Architecture

- One shared mock data/domain layer.
- Property-scoped routing and navigation.
- Config-driven tables, filters, tabs, and actions.
- UI version registry for v1.0, v2.0, and v3.0 experiments.
- Netlify-ready static deployment.
